### About

I'm a software quality engineer with **10+ years of experience** designing test automation frameworks and improving the reliability of enterprise SaaS applications, APIs, CI pipelines, and distributed services.

My engineering work spans **test architecture, Playwright automation, API testing, observability, performance, security, and accessibility**. At **Okta (June 2024–September 2026)**, I helped modernize a large E2E automation suite, improve CI feedback, and strengthen quality signals across services.

I'm extending that foundation into **AI Quality Engineering**: testing the reliability of LLM-powered applications, retrieval-augmented generation (RAG), and agent workflows.
